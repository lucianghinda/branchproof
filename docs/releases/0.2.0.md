# Proposed 0.2.0 release guide

This guide records the release steps for the proposed 0.2.0 release. The
version in `lib/branchproof/version.rb` is `0.2.0`, and the intended Git tag is
`v0.2.0`. The publication gem name is `branchproof`.

The release supports CRuby 3.3 and 3.4 with Minitest 5.x and Prism 1.x. It
supports ordinary Ruby ternary (`condition ? left : right`) predicates with
the existing `&&`/`||` condition handling. Ternary decisions report the
predicate outcome while preserving selected branch values and evaluation
order; nested executed predicates are recorded at each level. Rails is an
optional application dependency; the checked integration boundary is Rails
8.1.3.1 on CRuby 3.4.5. Terminal reports now provide readable decision and
condition labels, Minitest names, compact collision-safe IDs, witness and
counterpart details, and named supporting-test sets; JSON identifiers and
schema remain stable. The gem is intended to ship under the Apache License
2.0.

## Prepare and verify the gem

Run these commands from `gems/decisive` after the final source and license
changes are present:

```sh
mkdir -p pkg
gem build branchproof.gemspec --output pkg/branchproof-0.2.0.gem
gem install --local pkg/branchproof-0.2.0.gem
ruby -rdigest -e 'artifact = "pkg/branchproof-0.2.0.gem"; digest = Digest::SHA256.file(artifact).hexdigest; File.write("#{artifact}.sha256", "#{digest}  #{artifact}\n")'
```

The build must produce `pkg/branchproof-0.2.0.gem`. Check the installed command
from the same Ruby environment with:

```sh
gem list --local branchproof
ruby -rbranchproof -e 'abort unless Branchproof::VERSION == "0.2.0"'
```

Then run the repository's normal checks before publication:

```sh
bundle exec rake
rbs -I sig validate
```

The checksum file is a local release record and should be retained with the
artifact. Rebuild it whenever the gem changes.

## Local candidate verification

Repository verification completed on CRuby 3.4.5 with Rails 8.1.3.1 enabled:
174 tests, 147,570 assertions, and zero failures, errors, or skips. The
focused CRuby 3.3.6 / Prism 1.4 report and CLI run passed 36 tests and 194
assertions with zero failures, errors, or skips. RuboCop checked 58 files with
zero offenses, and `rbs -I sig validate` passed.

The ternary follow-up trials are recorded in
[agent-acl-ternaries.md](../trials/agent-acl-ternaries.md) and
[jekyll-agent-markdown-ternaries.md](../trials/jekyll-agent-markdown-ternaries.md).
The agent-acl run passed 134 tests and 1,533 assertions with 3 skips; all 20
ternaries were supported, with 185 eligible and 38 proven conditions (20.54%).
The Jekyll run passed 192 tests and 1,155 assertions with no skips; all 6
ternaries were supported, with 120 eligible and 99 proven conditions (82.5%).

The `pkg/branchproof-0.2.0.gem` candidate was rebuilt and installed locally.
All 25 packaged files are byte-identical to their source files, the package
reports the Apache-2.0 license metadata, and the SHA256 checksum is recorded
in the adjacent `pkg/branchproof-0.2.0.gem.sha256` file. The installed
`mcdc` CLI passed the three-test readable-report fixture, proved both
conditions, rendered the exact decision and condition expressions on their own
lines, displayed `ClassName#test_method` owners and eight-character
collision-safe IDs, and retained 64-character JSON identifiers. Rendering a
terminal report before the JSON report left the JSON reference byte-identical.
The installed CLI's prior ternary check passed separately, proving both
conditions and reporting the expected predicate vectors `[false, nil] =>
false`, `[true, false] => false`, and `[true, true] => true` despite the
fixture's inverse branch values. Report and embedded evidence metadata both
identify version 0.2.0. Keep the prior trial reports as historical evidence
of the narrower supported scope.

## Tag and publish later

Tagging and publication are intentionally not performed by this change. Once
the gem has passed the final checks and the repository has an authenticated
`origin`, the intended commands are:

```sh
git tag -a v0.2.0 -m "Release Branchproof 0.2.0"
git push origin v0.2.0
gem push pkg/branchproof-0.2.0.gem
```

There is currently no configured Git remote. Publication remains a separate
release action. As of 2026-09-09, the RubyGems API returned HTTP 404 for
`https://rubygems.org/api/v1/gems/branchproof.json`; that is an availability
check only and does not reserve the name. Before publication, configure the
intended GitHub repository and verify that its homepage and changelog URLs
resolve to the published repository.
