# Doctor Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers-ruby:subagent-driven-development. Follow TDD and separate specification/quality reviews.

**Goal:** Diagnose common setup problems before application or test execution.

**Architecture:** Reuse CLI resolution and source selection, then pass resolved
settings to a static Doctor report. Framework checks inspect gem metadata only.

**Tech Stack:** Ruby 4, Ruby standard library, existing Minitest/RSpec tests; no
new dependencies. See `docs/superpowers/specs/2026-10-03-doctor-design.md` for the
approved command and acceptance contract.

`lib/branchproof/cli.rb`, `lib/branchproof.rb`, `sig/branchproof.rbs`, and focused
CLI tests as needed. Preserve the existing eager Source/Prism load behavior.
