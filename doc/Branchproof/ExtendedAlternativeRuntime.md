# Module Branchproof::ExtendedAlternativeRuntime <a id="module-Branchproof-ExtendedAlternativeRuntime"></a>

|  |  |
| --- | --- |
| **Defined in** | lib/branchproof/extended_alternative_runtime.rb |

Runtime hooks for decisions whose native evaluation has a third path. Runtime
includes this module explicitly; it is kept separate so the ordinary two-path
helpers remain unchanged.
